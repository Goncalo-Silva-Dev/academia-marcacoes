# Academia de Marcações

Curso interativo, em português, para aprender a programar do zero e construir uma app de marcações:

- **Parte 0** — Antes de começar: como funciona uma app, terminal, instalação, Git e GitHub
- **Parte 1** — Python
- **Parte 2** — Web: HTML, CSS e JavaScript
- **Parte 3** — Bases de dados e SQL
- **Parte 4** — Como funciona uma app de marcações
- **Parte 5** — Projeto guiado: constrói a MarcaCabelo com Flask e SQLite

Tudo corre no browser (o Python via Pyodide e o SQLite via sql.js). O progresso fica guardado no browser de cada pessoa.

Site publicado com GitHub Pages a partir do ficheiro `index.html`.
